## 详解

### 🗺️ 主流地理数据存储格式详解表

#### 1. 核心数据库与容器格式（通常用于项目管理和海量数据）

|**格式名称**|**文件后缀**|**数据模型**|**开发者 / 标准**|**容量限制**|**核心优势**|**缺点与局限**|**最佳适用场景**|
|---|---|---|---|---|---|---|---|
|文件地理数据库<br><br>  <br><br>(File Geodatabase)|`.gdb`|矢量 / 栅格 / 拓扑|Esri (ArcGIS 专属)|单个表 **1 TB**|结构极其稳定，读写速度极快；支持复杂的拓扑规则、栅格镶嵌数据集和长字段名。|属于 Esri 闭源格式，离开 ArcGIS 环境后，其他软件（如 QGIS）只能读取，很难写入。|**ArcGIS 用户的绝对主力**。适合作为个人或小型团队的核心项目数据库。|
|**GeoPackage**|`.gpkg`|矢量 / 栅格|OGC (开放地理空间信息联盟)|最大支持 **140 TB**|真正的“单文件”数据库（基于 SQLite），开源且跨平台；支持多端（手机、电脑、网页）离线调用。|在极大规模的并发读写上，性能不如企业级数据库。|**跨软件协同**（如在 ArcGIS 和 QGIS 之间互传整个项目库），以及移动端离线地图。|
|企业级地理数据库<br><br>  <br><br>(Enterprise GDB)|无特定后缀<br><br>  <br><br>(SDE 链接)|矢量 / 栅格|Esri + 数据库厂商|取决于服务器硬件|支持**多用户同时在线编辑**、版本控制、历史归档；数据绝对安全。|部署成本极高，需要懂 SQL Server、Oracle 等 IT 数据库知识。|**大型企业或政府机构**的多部门协同制图。|
|个人地理数据库<br><br>  <br><br>(Personal GDB)|`.mdb`|矢量|Esri (基于微软 Access)|仅 **2 GB**|可以直接用 Microsoft Access 软件打开并编辑属性表。|容量太小，极易崩溃损坏；仅支持 32 位系统环境；**已被官方淘汰**。|仅用于**读取零散的老旧历史数据**。|

---

#### 2. 独立矢量与轻量级交换格式（通常用于数据共享和 Web 发布）

|**格式名称**|**文件后缀**|**数据模型**|**开发者 / 标准**|**容量限制**|**核心优势**|**缺点与局限**|**最佳适用场景**|
|---|---|---|---|---|---|---|---|
|**Shapefile**|`.shp`|矢量 (单一几何)|Esri (已完全公开)|单文件 **2 GB**|**地理界的“MP3”**，兼容性天下第一，任何 GIS 软件甚至 CAD 都能打开。|至少需要 3-7 个文件捆绑（少一个就报错）；字段名最多 10 个字符；不支持拓扑；容易出现中文乱码。|**对外发送或接收原始矢量数据**（如发给非 ArcGIS 用户）。|
|**GeoJSON**|`.json` / `.geojson`|矢量|IETF 标准|取决于文本解析能力|纯文本代码，人类肉眼可读；极其轻量，非常受程序员和前端开发者欢迎。|文件一大（比如几十 MB），文本解析就会导致浏览器或软件卡死；不支持复杂的坐标系转换。|**WebGIS 前端开发**（如百度地图、高德地图的网页端动态交互）。|
|**KML / KMZ**|`.kml` / `.kmz`|矢量 / 影像贴图|Google (现交由 OGC)|KMZ 无硬性限制|原生支持 3D 视角、地标弹窗、时间动画；KMZ 是 KML 的压缩包，还能把图标图片打包进去。|不适合进行复杂的空间分析（如求交、裁剪），属性数据存储能力弱。|**在 Google Earth 中进行三维展示**，或用于汇报演示。|

---

#### 3. 常见栅格存储格式（用于遥感影像和高程模型）

|**格式名称**|**文件后缀**|**数据模型**|**开发者 / 标准**|**容量限制**|**核心优势**|**缺点与局限**|**最佳适用场景**|
|---|---|---|---|---|---|---|---|
|**GeoTIFF**|`.tif` / `.tiff`|栅格|NASA / OGC|突破 4GB 需用 BigTIFF|最通用的带有地理坐标的图像格式；支持无损压缩，保留极高的科学数据精度。|文件体积通常非常庞大。|**存储航拍正射影像 (DOM)、数字高程模型 (DEM)**。|

## 💡 核心总结

- 如果你要自己做项目分析：坚决用 **`.gdb`**。

- 如果你要把数据发给别人：导出为 **`.shp`**。

- 如果你要做跨平台或开源开发：拥抱 **`.gpkg`**。

- 如果你要做网页动态效果：使用 **`.geojson`**。
