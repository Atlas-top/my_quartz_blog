# Markdown使用手册

> 写给每一个：  
> 想认真写作、做笔记、搭博客、做个人品牌的人

---

你有没有过这种体验？

- 想写一篇文章，**一半时间花在排版上**
- Word / WPS 越改越乱
- 从公众号复制到博客，格式全炸
- 过几个月再看自己的文章，**根本不想改**

如果你点头了，那我可以很肯定地告诉你一句话：

**你缺的不是工具，而是一种写作方式。**

---

## 一、Markdown 到底是什么？

> Markdown是一种轻量级标记语言，创始人为约翰·格鲁伯。它允许人们使用易读易写的纯文本格式编写文档，然后转换成有效的XHTML（或者HTML）文档。这种语言吸收了很多在电子邮件中已有的纯文本标记的特性。由于Markdown的轻量化、易读易写特性，并且对于图片、图表都有支持，目前许多网站都广泛使用Markdown来撰写帮助文档或是用于论坛上发表消息。如GitHub、Reddit、Discord、Diaspora、Stack Exchange、OpenStreetMap 、SourceForge、简书等，甚至还能被用来撰写电子书。许多大语言模型的输出也采用了Markdown的格式以支持简单的排版需求（如小节、粗体、数学公式等）。                  ——摘自维基百科

你写的不是“格式”，而是**结构**。

比如：

- `#` 表示标题  
- `-` 表示列表  
- ``` `表示代码  `

没有复杂按钮，没有鼠标拖拽，  
**只有键盘 + 思路。**

---

## 二、为什么越来越多人用 Markdown？

我先说结论，再解释原因。

> **Markdown 是内容创作者的“基础设施”。**

### 1️⃣ 写得快

你不需要反复调样式：

```markdown
## 这是一个标题
- 这是要点一
- 这是要点二
````

敲完就结束，逻辑清清楚楚。

---

### 2️⃣ 到哪都能用

Markdown 可以用在：

* 📒 笔记软件（Obsidian / Typora）
* 🌐 博客（Quartz / Hugo / Hexo）
* ✍️ 文档（GitHub / Notion / 语雀）
* 📱 公众号（使用 Markdown Nice 一键发布）

**一次写作，多处发布。**

---

### 3️⃣ 对“长期写作”极其友好

你今天写的文章，
**3 年后依然能轻松修改、复用、重组。**

---

## 三、最核心的 Markdown 语法（够你用 90%）

### 1️⃣ 标题结构（最重要）

```markdown
# 一级标题（一篇文章只有一个）
## 二级标题（章节）
### 三级标题（小节）
```

👉 **清晰的标题 = 清晰的思路**

---

### 2️⃣ 强调内容

```markdown
**加粗**
*斜体*
~~删除线~~
```

阅读体验立刻不一样。

---

### 3️⃣ 列表（公众号必备）

```markdown
- 第一件事
- 第二件事
- 第三件事
```

手机阅读时，**列表比大段文字友好 10 倍。**

---

### 4️⃣ 引用（增强“说服力”）

```markdown
> 这是一段引用
```

适合：

* 总结观点
* 引用名言
* 强调一句话

---

## 四、进阶一点：写给“认真创作者”的技巧

如果你不仅是写着玩，而是想**长期输出内容**，那这部分你一定要看。

---

### ✅ 1. 把文章当成“结构化内容”

不是随便写，而是：

* 先列标题
* 再填内容
* 每一节解决一个问题

Markdown 天然适合这种写作方式。

---

### ✅ 2. 技术 / 教程类内容，一定用代码块

````markdown
bash
git push origin main
````

读者一眼就知道：  
**这是“可以照着做的内容”。**

---

### ✅ 3. 善用提示块（高级排版）

在支持 Markdown 的平台中（如博客、笔记工具），你可以写出这样的结构：

```markdown
> [!tip]
> 这是一个写作小技巧
````

它非常适合用来：

* 提示重点
* 避坑说明
* 作者补充说明
