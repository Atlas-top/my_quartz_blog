Hello！小伙伴们！

时隔536天，Hello Metaverse频道（或者说我的个人 Blog ）终于再次上线！欢迎小伙伴们前来围观！☺️

早在 24 年的 8 月，一天在网上冲浪，那天在B站看到一个视频，使用 GitHub Pages + GitHub Action 就可以自动部署一个静态网站作为自己的个人 Blog，无需购买服务器，也无需购买域名！这极大的激发了我兴趣！因为，我很早就想要“拥有”一个自己的网站。但由于我非CS出身，加之自己的预算不足，更不可能去建一个动态网站！

那只能退一步选择弄一个“静态网站” ！

当时，在看了大量的视频教程，和技术博客或一些社区论坛，总算在 GitHub上弄好了！（虽然还一知半解的，但总归是弄好了）

虽然是弄好了，但还面临一个问题。那就是，在中国大陆地区我们是无法正常打开的，即使加载成功，里面的一些图片或视频会加载的十分缓慢！为了能够快速加载，我选择了“购买域名 + CDN”！

域名的购买，第一年的费用不算很贵（或者说很便宜），但第二年的价格就呈几何式上涨！所以我在腾讯云上（好像因为当时腾讯云有优惠）购买了一个域名，有加够了一年的 CDN 加速服务。这样我将我在 GitHub 部署的初始域名 atlas-top.asia 解析到腾讯云购买的这个域名上，在加上CDN的加速服务。果然！快了不少。

虽说，我弄好了这个“初代博客”，但还有一个很大问题，那就是如果我想写一些东西，或者在博客上传一些图片、视频之类的话就很麻烦！于是这个博客算是就这样毫无作用的放了一年，一直到域名到期，这个博客也算是结束了。（虽然它现在仍然可以访问  atlas-top.asia）😂

那么直到26年的1月，我在GitHub上发现一个开源项目 Quartz 4 一个快速的静态网站生成器，并且是完全基于Obsidian 来开发的（在Obsidian中写好文章，一键发布）
>Quartz is a fast, batteries-included static-site generator that transforms Markdown content into fully functional websites. Thousands of students, developers, and teachers are [already using Quartz](https://quartz.jzhao.xyz/showcase) to publish personal notes, websites, and [digital gardens](https://jzhao.xyz/posts/networked-thought) to the web.
>这是 Quartz 4 的官方说明

最终，第二版的Blog在2026/2/1成功上线！它已经通过cloudflare分发至全球各地！欢迎小伙伴们前来围观！😃
