![[content/Attachments/image-8.webp|620x515]]

### 2. 安装设置

### 3.登录账号（结束）

![[content/Attachments/image-12.webp|681x356]]

### 4. 汉化

> 由于 Antigravity 基于 VS Code 架构开发，汉化非常简单：
> 1. 启动 Antigravity。
> 2. 按下快捷键 Ctrl + Shift + P (Mac 为 Cmd + Shift + P)。
> 3. 输入 Install Extensions 并回车。
> 4. 在搜索框输入 “Chinese”，选择第一个 “Chinese (Simplified) (简体中文)” 安装。
> 5. 重启 IDE，界面即变为亲切的中文。
