## 1、什么是Mincraft？

>一句话定义：Minecraft 是由 Mojang Studios 开发的开放世界**沙盒游戏**，玩家在一个由方块构成的无限生成的三维世界中，进行探索、采集、合成、建造和生存。


>[!info]
>沙盒游戏（Sandbox Game）= 开放式玩法 + 创造工具 + 无强制目标

## 2、Mincraft历史发展



2009年5月 ──→ Markus "Notch" Persson 开始开发
     │
2009年5月17日 ──→ 首个公开版本（Classic）
     │
2010年 ──→ 生存模式加入（Survival Test）
     │
2011年11月18日 ──→ 正式版 1.0 发布（Java版）
     │
2014年9月 ──→ 微软以 25亿美元收购 Mojang
     │
2016年 ──→ 基岩版统一跨平台（C++重写）
     │
2017年 ──→ 教育版发布
     │
2019年 ──→ 村庄与掠夺更新（1.14）
     │
2020年 ──→ 下界更新（1.16）
     │
2021年 ──→ 洞穴与山崖更新（1.17-1.18）
     │
2022年 ──→ 荒野更新（1.19）
     │
2023年 ──→ 足迹与故事更新（1.20）
     │
2024年 ──→ 棘巧试炼更新（1.21）
     │
2025年 ──→ 继续更新中...
