## 1.模组加载器 (Mod Loader) 

**模组加载器 = 让模组能够运行的"翻译官"和"管理员"**

原版 Minecraft ──→ 无法识别任何额外代码
     ↓
安装加载器 ──→ 修改游戏核心，建立"模组接口"
     ↓
放入模组文件 ──→ 加载器识别、加载、协调各模组
     ↓
启动游戏 ──→ 模组功能正常运行

>本质：一种修改过的 Minecraft 核心程序，在正版基础上增加"钩子(Hook)"，允许第三方代码安全注入。

| :--------- | :-------------- | :-------------- | :----------- | :----------- |

| **适用版本**   | 1.12.2-1.20+    | 1.14-1.20+      | 1.18+        | 1.20.1+      |
| **代码哲学**   | 重量级，功能全面        | 轻量级，快速迭代        | 比 Fabric 更开放 | Forge 精神续作   |
| **模组数量**   | ⭐⭐⭐ 最多（10万+）    | ⭐⭐ 快速增长（2万+）    | ⭐ 较少         | ⭐ 新兴         |
| **大型模组支持** | ⭐⭐⭐ 工业/魔法模组首选   | ⭐⭐ 多为辅助/优化      | ⭐ 待发展        | ⭐⭐ 继承Forge   |
| **更新速度**   | 慢（大版本需数月）       | ⭐⭐⭐ 快（数日适配）     | ⭐⭐⭐ 快        | 待观察          |
| **性能开销**   | 较大              | ⭐⭐⭐ 极小          | 极小           | 较大           |
| **学习门槛**   | 高（复杂API）        | ⭐⭐⭐ 低（简洁文档）     | 低            | 高            |
| **代表模组**   | IC2/神秘时代/Create | Sodium/Iris/优化类 | 多为Fabric移植   | 原Forge生态     |
| **安装方式**   | 启动器自动安装         | 启动器自动安装         | 手动/启动器       | 启动器自动        |

## 3.加载器工作原理图解

┌─────────────────────────────────────┐
│           你的电脑                   │
│  ┌─────────────────────────────┐   │
│  │      启动器 (PCL/HMCL)       │   │
│  │   ├─ 下载 Minecraft 核心     │   │
│  │   ├─ 安装 加载器 (Forge等)   │   │
│  │   └─ 管理 模组文件 (.jar)    │   │
│  └─────────────────────────────┘   │
│              ↓                     │
│  ┌─────────────────────────────┐   │
│  │    加载器修改后的游戏核心    │   │
│  │   ├─ 原版 Minecraft 代码    │   │
│  │   ├─ 加载器注入的接口层      │   │
│  │   └─ 各模组代码 (A.jar/B.jar)│   │
│  └─────────────────────────────┘   │
│              ↓                     │
│         JVM 运行 (Java版)           │
